# PL Data Plugins

This repository makes every-day data engineering tasks simpler and more efficient.

## Repositories to clone

Clone these repositories into the same parent directory:

```text
path/to/repositories
- /di-pipelines
- /di-pyjobs
- /di-scheduling
- /di-schema-definitions
- /pl-application
```

## Clone URLs

```bash
git clone git@github.com:precisionlender/di-pipelines.git
git clone git@github.com:precisionlender/di-pyjobs.git
git clone git@github.com:precisionlender/di-scheduling.git
git clone git@github.com:precisionlender/di-schema-definitions.git
git clone git@github.com:precisionlender/pl-application.git
```

## Set up the workspace

In Codex, run `/setup` to add these repositories as submodules and create a dedicated worktree for each one.
